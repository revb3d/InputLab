Why it is built this way

Fast control surface for repetitive input flows, not a bloated macro suite.

The design target is short setup time, clear state, and reliable switching between keyboard and controller automation. The UI stays dark, focused, and operational.

Global keyboard holds

Bind one hotkey to hold another key down until toggled off.

Profile-driven controller macros

Separate hotkeys, notes, window detection, recorder support, and step timing per profile.

Real visibility while running

Live progress, status overlays, session stats, and active state indicators reduce guesswork.
